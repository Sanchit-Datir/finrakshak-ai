## Decisions taken (owner to confirm)

- **Products (9):** two new product ids `business` and `education` with their own document
  checklists. "MSME loan" is the existing `msme_working_capital` and "Farmer loan" the existing
  `agri_term` (relabelled), so existing records and checks keep working. The other products (Kisan
  Credit Card, warehouse receipt, MSME term, personal) stay only for existing records and are no
  longer offered in the form. New drafts default to Farmer loan. "Big loan" was read as Business
  loan; say if a separate "large loan" product is wanted.
- **Branches (7):** only display names change; ids stay so stored scores and data keep matching.
- **Borrowers (12, 13):** read as one rule: most open findings first; equal counts ordered Urgent →
  Needs attention → Routine → no priority.
